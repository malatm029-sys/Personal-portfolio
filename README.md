# Personal Portfolio Website

A full-stack personal portfolio website built using Flask, MySQL, HTML, CSS, and JavaScript.

## Features

- Home section
- About Me section
- Skills section
- Dynamic Projects section
- GitHub project links
- Contact form
- Contact messages stored in MySQL
- Responsive design for mobile and desktop
- JavaScript form validation

## Technologies Used

- HTML
- CSS
- JavaScript
- Python
- Flask
- MySQL
- Git & GitHub

## Database

The project uses MySQL to store:

- Project details
- Contact messages
